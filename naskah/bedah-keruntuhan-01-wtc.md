## Hook (≤ 3 dtk)
Dipilih: "Gedung baja kok bisa runtuh cuma karena api?" (kata yang sudah dicari/ditanyakan orang, bukan teka-teki angka)
Alternatif: (b) "Katanya api nggak bisa runtuhin baja? Bisa." (c) "Bajanya nggak meleleh. Tapi gedungnya tetap runtuh."

## Beat (VO ±125 kata)
| # | Detik | VO | Visual (gaya "blueprint forensik") |
|---|---|---|---|
| 1 | 0–3 | Gedung baja kok bisa runtuh cuma karena api? | Siluet menara dari garis kapur di latar biru tua, api oranye di atas. Judul besar. |
| 2 | 3–10 | Api di dalam gedung itu paling panas sekitar seribu derajat. Baja baru meleleh jauh di atas itu. | Dua batang termometer. Api berhenti di ±1.000 °C; garis leleh ±1.500 °C (perkiraan) tetap tinggi. Jarak di antaranya diberi tanda. |
| 3 | 10–18 | Tapi baja nggak perlu meleleh. Cukup panas buat jadi lemas. Makin panas, makin nggak kuat dia nahan beban. | Grafik tanpa angka: kekuatan baja turun saat suhu naik; zona "lemas, belum meleleh". |
| 4 | 18–26 | Biasanya baja gedung dilapisi pelindung api. Tabrakan pesawat mengelupas lapisan itu, jadi bajanya langsung kena panas. | Balok baja berlapis abu-abu; lapisan terkelupas, balok memerah. |
| 5 | 26–36 | Yang lemas duluan lantainya. Lantai melorot, lalu narik tiang di tepi gedung ke arah dalam. | Penampang gedung disederhanakan: lantai melengkung ke bawah, panah menarik tiang tepi ke dalam. |
| 6 | 36–45 | Tiang yang ketarik miring itu akhirnya tekuk. Bagian atas gedung jatuh menimpa lantai di bawahnya. | Tiang menekuk; blok atas turun dan meremukkan lantai di bawahnya. |
| 7 | 45–50 | Di menara utara, tiangnya terlihat melengkung ke dalam lima menit sebelum runtuh. | Garis waktu 10:23 → 10:28, label "NIST". |
| 8 | 50–55 | Makanya lapisan pelindung api di baja itu penting banget. Menurutmu, gedung mana lagi yang mau dibedah? Follow buat fakta rumah berikutnya! | Kata "LEMAS" membesar; pertanyaan komentar; tombol follow. |

## Tanda visual dan sumber
- Teks kecil tetap di layar: "Diagram disederhanakan, bukan skala asli" dan "Sumber: NIST NCSTAR 1".
- Beat 2: 1.000 °C = suhu udara maksimum menurut NIST; 1.500 °C = (perkiraan).
- Beat 3: grafik hanya bentuk kurva, tanpa angka, sampai angka NIST terverifikasi.
- Beat 7: 10:23 dan 10:28 untuk sisi selatan WTC 1 (menara utara).

## [⚠ CEK] sebelum ACC
- Kata-kata NIST untuk tahap akhir runtuh di beat 6 (saat ini diparafrase aman).
- Apakah "sekitar seribu derajat" cukup dengan sumber sekunder (Nextgov atas FAQ NIST). Idealnya dicek langsung di nist.gov.
- Nada: hormat, tanpa rekaman orang atau korban.
